# Alpenwerk

Локальная адаптивная SPA вымышленного швейцарского банка. React 19, TypeScript и Vite; без сервера, платежей, реальных счетов и отправки заявок.

## Запуск

```sh
npm install
npm run dev
```

Vite выводит локальный адрес, обычно `http://localhost:5173`. Для production-проверки: `npm run build`, затем `npm run preview`.

## Возможности

- Полные ручные переводы RU / DE / EN, локальное сохранение языка, форматирование сумм через `Intl.NumberFormat`.
- Вклады Basis (6 мес.), Panorama (12 мес.), Horizon (24 мес.), подробности и сравнение.
- CHF / EUR / USD, слайдер и ввод суммы 10 000–1 000 000, срок, ежемесячная капитализация, интерактивный SVG-график и доступная помесячная таблица.
- Форма с валидацией, параметрами выбранного вклада и локальным подтверждением. Имя и email хранятся только в памяти текущей страницы.
- Мобильное меню, FAQ, управление клавиатурой, native dialog с фокусом и поддержка reduced motion.

Ставки и продукты учебные. Валюты не конвертируются. Доход рассчитывается до налогов и комиссий; без капитализации общая сумма означает капитал плюс накопленные проценты.

## Проверка

```sh
npm test
npm run build
```

Playwright использует установленный Google Chrome; для другого браузера измените `channel` в `playwright.config.ts`. Тесты запускают локальный Vite автоматически, если он еще не работает.

Для визуальных артефактов при запущенном Vite на порту 5173:

```sh
npm run design:shots
npm run design:scan
```

`DIRECTION.md` описывает концепцию, контент, токены и три исследованных направления. `CRITIQUE.md` содержит независимую оценку двух раундов. Скриншоты: `design/shots/r2`; исследования: `design/explore.html`.
